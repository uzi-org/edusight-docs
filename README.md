# EduSight Africa documentation

Product and integration documentation for **EduSight Africa**, published at **https://uzi-org.github.io/edusight-docs/**.

EduSight gives schools early-warning signals and practical support guidance, so that learners who are starting to struggle are noticed and helped in time. It works as a platform for teachers and school leaders, and as an API that plugs into existing school and student management systems. It is part of [Uzi Org](https://github.com/uzi-org).

Start with the [home page](docs/index.md), [how EduSight works](docs/how-it-works.md), or the [integration guide](docs/integrate/index.md).

## About this repository

This repository holds only the published documentation. The content is maintained in EduSight's private source repository and copied here automatically, so changes made directly here will be overwritten. To suggest a correction, open an issue.
