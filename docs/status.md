# Product status

*Last updated 28 October 2026.*

EduSight is in **early development**. It has not yet been piloted with a school, and its signals have not been validated against real learner outcomes. We would rather say that plainly than overstate it.

## Available now

| Area | What works |
| --- | --- |
| **Platform** | Role-based access for teachers, school administrators, parents, content editors and platform administrators; learner records with classes; assessments in any subject; support queue; interventions; parent view grouped by school and class; home observations; school reports and CSV export; installs to the home screen and shows an offline notice |
| **Learner profiles** | Every subject against the learner's own history; strengths with how to maintain them; growth areas with how to improve; extracurricular activities and how they connect to learning |
| **Signals** | Support level (routine / watch / urgent), plain-language drivers, confidence, missing-data warnings, support needs with owners and review dates, human-review flag |
| **Getting data in** | Photo capture of paper mark sheets with review before saving; Excel/CSV results import with per-class templates; learner import from CSV |
| **Administration** | Invitations or temporary passwords for new accounts, teacher class assignments, guardian links, learner enrolment and CSV import, an access log of who viewed which learner (also visible to families for their own child), school details, API keys, settings for every role |
| **Resources** | Library filtered by category, level, language and tag; EduSight Studio for writing and publishing resources in a visual editor |
| **Integration** | API keys; roster sync, single or up to 500 per call; idempotent events; assessments; stateless prediction; signed webhooks with retries; Python and TypeScript SDKs |
| **Languages** | English, Kiswahili |

## In development

- A family view of teacher-approved suggestions, with the approval recorded
- Per-school settings for thresholds, terminology and intervention templates
- A better reader for handwritten marks, trained on corrections from schools that opt in
- Fairness and accuracy evaluation with partner schools, on real, consented data

## Planned

- Single sign-on for school accounts: OAuth2/OIDC, Google and Microsoft
- Embeddable widgets and LTI for learning platforms
- xAPI/Caliper event ingestion
- Offline data capture that syncs when a connection returns
- More African languages, each reviewed by native speakers

## Working with us

We are looking for schools, school-management providers and education programmes to pilot EduSight with. Pilots will help us test whether the signals really help learners, and they are the only honest way to find out. Contact Uzi Org through [github.com/uzi-org](https://github.com/uzi-org).
